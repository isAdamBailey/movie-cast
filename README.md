# movie-cast

Nuxt 4 + TypeScript app for searching movies and displaying cast members via secure Nitro TMDB routes.

## Setup

1. Install dependencies:

```bash
npm install
```

2. Create a local env file:

```bash
cp .env.example .env
```

3. Set `TMDB_API_KEY` in `.env`.

## Development

```bash
npm run dev
```

## Production

```bash
npm run build
npm run preview
```
